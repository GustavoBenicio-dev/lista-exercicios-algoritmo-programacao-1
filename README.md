# Lista de Exercícios — Algoritmo e Programação

Repositório com a resolução de 30 exercícios da disciplina **Algoritmo e Programação**, cada um implementado em **Python, Java e C++**, como prática de lógica de programação e sintaxe comparada entre linguagens.

## Objetivo

Fixar os fundamentos de programação (variáveis, constantes, tipos de dados e operadores aritméticos/relacionais) implementando a mesma lógica em três linguagens diferentes, reforçando a compreensão de conceitos independentes de sintaxe.

## Conteúdo

| Bloco | Tema | Questões |
|---|---|---|
| 1 | Variáveis, Constantes e Tipos de Dados | 1–10 |
| 2 | Operadores Aritméticos | 11–20 |
| 3 | Operadores Relacionais | 21–30 |

## Estrutura

Cada questão possui sua própria pasta, contendo a mesma solução nas três linguagens:

```
questao01/
├── main.py
├── Main.java
└── main.cpp
questao02/
├── main.py
├── Main.java
└── main.cpp
...
```

## Como executar

**Python**
```bash
python main.py
```

**Java**
```bash
javac Main.java
java Main
```

**C++**
```bash
g++ main.cpp -o main
./main
```

## Tecnologias

- Python 3
- Java (JDK)
- C++ (g++)
- VS Code
